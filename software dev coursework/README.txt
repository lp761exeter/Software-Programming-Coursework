This project was made with and for the usage of Maven
JUnit can be used to run the tests directly, but I don't recommend it.

Prerequisites:
- Have Java installed correctly; https://www.youtube.com/watch?v=SQykK40fFds
- Have JUnit 5 installed correctly

To run the tests with Maven:

- Have Maven installed correctly; https://www.youtube.com/watch?v=B6Gx6lJOlYc&t=7s
- Navigate to this file's directory in your operating system's terminal (in windows, right click the directory's whitespace and click open in terminal)
- type "mvn test" and press enter
